This release brings the Go security fixes to the release binaries, and makes the daemon easier to install: macOS binaries are signed and notarized, Homebrew is supported, and Linux users get DEB and RPM packages. Nothing changes in how the daemon behaves or how you configure it.

Download the archive for your platform from the assets below, or update with your package manager.

## New

- **macOS binaries are signed and notarized.** Both Darwin builds now pass Apple's notarization before they are archived. By @crmne.
- **Homebrew install.** `brew install crmne/tap/mqtt-alive-daemon`, with `brew services` support. By @crmne.
- **DEB and RPM packages for Linux.** They are attached to the release for amd64 and arm64. By @crmne.

## Fixed

- **Standard library security fixes.** Binaries are now built with Go 1.26.10, which fixes known vulnerabilities in code the daemon reaches, including TLS certificate checks during the broker connection and URL parsing of the broker address. By @crmne.
- **Updated `golang.org/x/net` to v0.62.0.** This clears the security advisories against that module. The daemon does not include the affected HTML parser, so it was not exposed to them. By @crmne, from Renovate's [#17](https://github.com/crmne/mqtt-alive-daemon/pull/17) and [#18](https://github.com/crmne/mqtt-alive-daemon/pull/18).
